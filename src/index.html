Settings


Appearance

Theme

The color scheme for the whole app.

Interface Font

The font for the whole app: sidebar, menus, and also notes if you do not set a font for the editor.

Reset

Put every setting back to its default. Notes are untouched.

Editor

Show Line Numbers

Number every line of the note, like a code editor does.

Font Size

The height of the text.

Font Family

A font applied to the editor text.

Line Height

The space between lines.

Word Spacing

Extra space between words. (Caret will have an offset bug on macOS and iOS due to WebKit.)

Line Width

The maximum width of the text, centered in wider windows.

Interface

Show Sidebar at Startup

Start the app showing the sidebar with your notes already open.

On Opening a Note

Whether opening a note focuses the editor, and where the caret lands.

Window Controls

The style of the minimize, maximize, and close buttons. Automatic follows the system.

Sync

Sync With Paired Devices

Keep notes identical across your own devices. Syncing happens directly between them on your network, no cloud or account involved.


Device Name

How this device introduces itself to your other devices.

Paired Devices

The devices this one trusts and syncs with.

Pair by Address

If a device is not found automatically, type the address shown in this section on that device to pair with it directly.

Shortcuts

Write shortcuts like "Cmd/Ctrl+Shift+P" or "Option/Alt+Cmd/Ctrl+C", where Cmd means ⌘ and Option means ⌥ on Mac. Option (⌥) and Alt act as the same key. Leave a field empty to turn that shortcut off.

Minoo

Settings are saved to a settings.toml file. Notes are stored as .md Markdown files. You can easily back up your notes and copy your settings to another device. Restart Minoo when you change note and setting files directly.
